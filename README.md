## 🎯 What is ChronoPom?

<img align="right" src="https://media.giphy.com/media/RbDKaczqWovIugyJmW/giphy.gif" width="270" />

**ChronoPom** is a sleek, intelligent, and beautifully crafted **Pomodoro-based Productivity Tracker** that transforms the way you manage time and tasks.

Built with **AngularJS, Firebase & GSAP animations**, it keeps you in a deep focus state — helping you hit your goals one session at a time.

Whether you're a **student** grinding through exams or a **professional** shipping projects — ChronoPom keeps you disciplined, rewarded, and on fire. 🔥

## 🚀 Quick Start

```bash
# Step 1 — Clone the repository
git clone https://github.com/asmitajarhalli123/ChronoPom.git

# Step 2 — Navigate to the project folder
cd ChronoPom/ChronoPom

# Step 3 — Open directly in your browser
open index.html
# or just double-click index.html in your file explorer
```

> ✅ **Zero build steps!** This is a plain HTML/CSS/JS project — just clone and open.

## 🔥 Firebase Configuration

To connect your own Firebase project, update the config block in `app.html`:

```javascript
// 🔐 Replace with YOUR Firebase credentials
const firebaseConfig = {
  apiKey:            "YOUR_API_KEY",
  authDomain:        "your-project.firebaseapp.com",
  projectId:         "your-project-id",
  storageBucket:     "your-project.appspot.com",
  messagingSenderId: "YOUR_SENDER_ID",
  appId:             "YOUR_APP_ID"
};
```

Enable these services in your Firebase console:

```
✅ Authentication  →  Email / Password provider
✅ Firestore       →  Native mode database
```
